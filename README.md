# Predict Car Prices – Pakistan

## Project Overview
This project uses Machine Learning to predict used car prices in Pakistan based on vehicle characteristics such as brand, model, manufacturing year, mileage, engine capacity, fuel type, transmission, and condition.

## Project Objectives
- Perform Exploratory Data Analysis (EDA).
- Clean and preprocess the dataset.
- Train and compare multiple regression models.
- Evaluate model performance using MAE, RMSE, and R².
- Tune the selected model.
- Save the trained model for future predictions.
- Develop a Streamlit web application.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Streamlit
- Joblib
- Google Colab

## Project Files
- `Car_Price_Prediction.ipynb` – Complete model development notebook.
- `car_price_model.pkl` – Trained machine learning model.
- `feature_info.pkl` – Model feature information.
- `pakistan_car_prices_50000.csv` – Dataset.
- `app.py` – Streamlit application (when added).
- `requirements.txt` – Project dependencies.

## Dataset Information
The project uses a synthetic dataset containing 50,000 records representing used cars in Pakistan. It is intended for educational and model-development purposes and does not represent verified real-world market listings.

## Model Evaluation
The trained regression models are evaluated using:
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
